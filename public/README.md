# Pasta de Arquivos Públicos Estáticos (Vite)

Arquivos colocados nesta pasta são servidos diretamente na raiz do sistema:
- Para colocar a sua logotipo via arquivo estático, salve sua imagem como:
  `/public/logo.png` (ou `.jpg`, `.svg`, `.webp`)
- Ela ficará acessível imediatamente pelo caminho `/logo.png`.
- Você também pode fazer o upload ou informar a URL da sua logo diretamente na tela de **Configurações**.
